# Evidências visuais da apresentação

O enunciado do Trabalho 4 pede screenshots ou GIFs da aplicação em funcionamento. Não foram incluídas imagens simuladas, porque a aplicação não pôde ser iniciada neste ambiente de preparação (o registro npm ficou indisponível). Depois de executar o projeto com Docker, salve aqui capturas reais, por exemplo:

1. `painel-inicial.png` — interface aberta e conexão ativa.
2. `evento-ao-vivo.png` — duas abas visíveis após registrar um empréstimo ou uma devolução e observar a atualização sincronizada.
3. `documentacao-api.png` — `/docs` mostrando a documentação OpenAPI.

Atualize esta página e a seção de evidências do README com os arquivos reais antes de entregar.
